# GIVEN Project Notes

## Identity

- Title: GIVEN
- Package/build name: `given`
- Format: Ren'Py visual novel

## Content directories

- `game/script.rpy` contains the current entry-point script.
- `game/options.rpy` contains metadata, window title, save directory, and build package name.
- `game/images/`, `game/audio/`, and `game/gui/` are reserved for production assets.

## Build policy

Generated builds and export artifacts belong in `builds/` or `exports/` and should not be committed.
